# 课程生产线框原型

状态：D1 结构原型已实现，视觉低保真，业务数据为固定模拟值。默认体验采用任务引导式流程，工程状态仅在评审模式出现。

这个目录保存“课程目标到课程对象”原型的说明、评审记录和导出快照。可运行代码位于 `apps/workbench`；它回答产品布局和状态模型是否成立，不承担真实 ClassIn 集成或最终品牌视觉。

启动：`pnpm dev`，打开 `http://localhost:4173/?variant=focus`。加入 `review=1` 可打开评审模式，切换方案视图、过程视图并查看异常状态。原型使用内存状态，回到工作台即可重新开始。

原型完成后应具备：

- 三种可切换工作台布局方向；
- 同一套主链状态和固定模拟数据；
- 对目标、计划、上下文、Artifact、审批、回执和复查的可视化；
- 冲突、部分成功、权限拒绝和恢复状态；
- 一条命令启动和重置。
- 默认教师路径：选择任务 → 补充目标 → 查看方案 → 确认保存。

## 详细交互与状态原型

[交互与状态原型](./interaction-state-prototype.html)用于验证第一版产品方案的状态模型，而不是最终 UI。它是一个可以直接双击打开的单文件原型，支持自由操作和三条引导场景：

- 正常完成：从目标推进到规则校验、审批和执行回执；
- 阻断意见：观察 AI 修订后意见仍需教师再次审教验证；
- 版本冲突：观察写回冲突不会覆盖课程事实，WorkBuddy 方案仍被保留。

原型验证的问题是：审教意见、版本、校验、确认、审批和回执是否能组成一条教师可理解、可恢复的闭环。通过双击 HTML 文件即可运行，不需要安装依赖或启动服务。
