# WorkBuddy V1 Golden Samples

## 1. 用途

这些样本用于校准结构、密度、交互关系和视觉气质，不是待复刻页面。所有样本均来自 `/Users/eeo/Documents/claudecode/classin-pc-optimizer` 的已存在证据或视觉回归快照。

## 2. ClassIn PC 样本

| ID | 文件 | 证明什么 | 不证明什么 |
|---|---|---|---|
| `CPC-01` | `classin-pc/CPC-01-teacher-home-1440x900.png` | ClassIn 教师 Shell、工作面、紧凑导航、品牌绿比例和 `1440×900` 构图 | WorkBuddy 首屏必须沿用首页布局 |
| `CPC-02` | `classin-pc/CPC-02-teacher-tasks-detail-1440x900.png` | 高频列表、详情就近展开、任务状态与业务上下文关系 | Agent 历史必须使用相同字段或栏宽 |

## 4. 使用方法

每个页面方案必须说明：

1. 借鉴哪个样本的哪条原则；
2. 该原则解决什么 ClassIn 教师任务问题；
3. 哪些外观或业务结构被明确拒绝；
4. 方案在 `1440×900` 下是否仍有单一主焦点和可达主行动。
