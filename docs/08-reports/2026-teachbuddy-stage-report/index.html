真实 Runtime、Context Engine、模型网关、恢复与成本治理。

⌁

Skills / MCP 资产

教育方法、结构化输入输出、规则校验和可复用工具。

✓

质量与安全

权限、租户隔离、审计、评价、E2E、灰度与可观测性。

组织方式：每个共享 Module 有单一 Owner；每条业务场景另设一位纵向负责人，负责从 UI 到 Receipt 的端到端结果。
岗位名称可以按公司现状调整，但职责不能缺。不要只按“前端/后端/AI”横切，否则一个场景无人对端到端结果负责。建议先为作业提醒或单题讲解选一个纵向负责人。
