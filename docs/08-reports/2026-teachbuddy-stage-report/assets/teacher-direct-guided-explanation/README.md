# 老师私聊学生：TeachBuddy 个性化解题关键帧

本组截图来自教师端真实 Demo 流程，统一为 `1600 × 900`，使用橙红色编号标出关键操作和产品价值点。

## 建议讲解顺序

1. `01-学生私聊与单题讲解入口.png`
   - 学生只需要说明课程、作业、题号和卡点；
   - TeachBuddy 自动带入当前学生私聊 Context；
   - 老师选择“单题讲解”。
2. `02-确认生成单题讲解.png`
   - TeachBuddy 根据当前消息组织生成要求；
   - 老师确认后提交生成。
3. `03-教师审核最终话术与讲解内容.png`
   - 交付物是最终可发送话术及其中的讲解链接；
   - 老师可修改话术、预览链接，并继续编辑讲解内容。
4. `04-预览题目与分步解题过程.png`
   - 展示真实数值题；
   - 展示分步推导、公式计算和自检点。
5. `05-预览结果验算与完整答案.png`
   - 展示结果方向、守恒验算和完整答案。
6. `06-老师逐步编辑讲解内容.png`
   - 每一步讲解、公式与推导均可由老师修改。
7. `07-教师确认完整答案并发送.png`
   - 老师审核完整答案；
   - 系统明确最终接收内容，教师确认后才执行发送。
8. `08-发送成功与学生可打开链接.png`
   - 最终话术和讲解链接写入当前学生私聊；
   - TeachBuddy 返回可追溯的发送结果。

## 汇报选图建议

- **三图精简版：** 01 → 03 → 08。
- **五图完整业务链：** 01 → 03 → 04 → 07 → 08。
- **产品评审完整链：** 按 01—08 顺序展示。
