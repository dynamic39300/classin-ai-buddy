## 2. Round 0 的有效贡献

1. 建立了对原始 Excel 结构、体量和可处理性的初步认识；
2. 识别了单聊与群聊需要分开研究，群聊还必须区分师生班级群与教学运营/管理群；
3. 识别了固定窗口截断、角色缺失、会话关系不可推断、自由文本隐私等关键风险；
4. 证明了只看关键词、多标签规则和总量排名会造成误判；
5. 形成了可复用的读取、聚合、抽样、脱敏和校准脚本原型；
6. 促成了正式研究必须先形成方法共识、再执行分析的共同判断。

## 3. 暂停使用的结论

以下内容在正式阶段完成独立人工标注与质量验证前，均不得作为产品重点或需求优先级依据：

- “课程时间与课堂入口”“知识答疑与讲解”“作业提交与订正”等主题的真实发生率；
- 规则命中消息数所形成的主题排名；
- 规则标签覆盖会话所形成的需求普遍性判断；
- 以 30 分钟切分得到的 Episode 数、回应率或收口率；
- 对单聊关系是师生、学生之间或员工之间的自动推断；
- 将所有班级群直接理解为老师—学生教学群；
- 从上述数字直接推导方案一、方案二、方案三或具体 AI Feature 的优先级。

## 4. 正式研究必须解决的问题

| 问题 | Round 0 的缺口 | 正式阶段要求 |
| --- | --- | --- |
| 分析单位 | 消息、固定会话槽位、30 分钟 Episode 混用 | 每个指标唯一声明消息、完整会话、片段、任务或参与者中的一种 |
| 分子与分母 | “占教学锚点”易被误读成发生率 | 指标字典必须列出公式、排除项、重复计数和适用范围 |
| 语义真值 | 关键词/规则多标签，无可靠精度 | 先做双人标注小实验、分歧仲裁和精度评估 |
| 样本代表性 | 固定 100 行与规则命中样本可能严重偏置 | 分层概率样本与发现性样本分轨，记录随机种子和丢样原因 |
| 角色关系 | 单聊缺老师/学生角色；群聊角色复杂 | 角色未知时保持未知；有证据后再分层，不靠内容猜身份 |
| 群类型 | 班级群中混有教学管理与教务沟通 | 建立群类型判定规范与“无法判断”类别 |
| 完整性 | 固定窗口可能缺上文、下文和结局 | 记录左截断、右截断、缺失附件、缺失系统事件 |
| 结果与价值 | 无已读、解决、结果、耗时和满意度事实 | 不用回复代理冒充解决；缺失则明确缺失 |
| 数据修正 | 脏数据处理容易静默改变事实 | 原始层只读，清洗层版本化，每条修正有规则、影响量和可逆记录 |
| 隐私安全 | 原始消息含真实个人信息 | 原文不入仓库；最小必要读取；派生样本脱敏且仍按受限数据管理 |

## 5. 阶段切换 Gate

Round 0 已关闭。正式大规模分析在以下条件同时满足前不启动：

1. 研究问题和“本轮不回答什么”经双方确认；
2. 数据字典、缺失与脏数据处理规则经审阅；
3. 抽样框、分层逻辑、随机方法和样本保全机制经确认；
4. 标注手册、边界案例和仲裁流程通过小规模试标；
5. 指标字典明确每个分子、分母、去重与多标签口径；
6. 已约定可以支持什么结论、不能支持什么结论。
