# ClassIn IM 真实聊天数据预研 Round 0 封存包

本目录是正式事实研究启动前的预研阶段快照。它保存 2026-08-28 形成的数据探索、规则分析、校准记录、方法脚本和阶段性产品映射，目的是支持复盘与来源追溯，不再作为当前研究结论或产品优先级依据。

## 1. 阶段结论

Round 0 完成了“看见数据、理解字段、试跑方法、暴露问题”的任务，但没有建立足以指导产品决策的语义真值。正式阶段必须重新约定研究问题、数据治理、抽样设计、标注规范、计算口径和质量门槛。

| 资产层级 | 当前处理 | 使用边界 |
| --- | --- | --- |
| 数据结构事实 | 保留 | 可用于理解工作簿结构、样本规模、字段缺口和技术可处理性 |
| 聚合描述 | 有条件保留 | 仅在分子、分母、分析单位和缺失条件明确时引用 |
| 规则标签与主题比例 | 封存 | 只能证明规则命中，不能作为真实教学需求发生率 |
| 响应、闭环与价值代理 | 封存 | 无已读、解决、结果或人工真值时，不得表述为真实效果 |
| 方案一、二、三映射 | 暂停 | 仅作为当时的产品假设，不牵引正式事实研究 |
| 方法脚本 | 保留待审 | 可复用读取、脱敏、版本化等机械能力；语义规则必须重审 |

## 2. 封存内容

- `snapshots/research/`：两份预研方法与聚合分析的原样快照；
- `snapshots/product/`：两份基于 Round 0 推演的产品假设原样快照；
- `snapshots/tools/`：四个数据读取、分析、抽样与校准脚本；
- `snapshots/outputs/`：首轮匿名聚合工作簿；
- [阶段收口记录](./STAGE-CLOSEOUT.md)：记录阶段经过、保留项、作废项和遗留问题；
- [快照清单](./SNAPSHOT-MANIFEST.md)：记录来源、大小、敏感等级和是否入包；
- [SHA-256 校验清单](./CHECKSUMS.sha256)：用于验证仓库内快照未被改变。

## 3. 未纳入封存包的受限数据

原始聊天工作簿与人工复核工作簿含真实消息文本或残余自由文本风险，因此只在 [快照清单](./SNAPSHOT-MANIFEST.md) 中登记绝对位置、文件大小和 SHA-256，不复制到仓库。任何后续访问都应遵循最小必要、只读、派生数据脱敏和版本留痕原则。
