## 3. 能力页面与“我的文件”重构

### Prompt 24｜参考腾讯 WorkBuddy 管理 AI 生成文件

> 你参考一下附件目录里的文件夹。我参考了腾讯 workBuddy 对“我的文件”这类生成文件的管理方式：对于本地生成的资料，它按照一定规则进行组织，让用户能快速定位和回溯自己在什么时间生成了什么内容，从而充分复用。
>
> 这是一个很好的管理入口。因为很多时候 AI 很容易生成大量内容，但用户管理起来往往没有章法、非常凌乱，所以这个入口的设计非常有必要。
>
