## 0. 实例证据是结构修改的硬门禁

本候选树不是按“名称是否整齐”或“一个 L2 下面有几个 L3”凭空整理出来的。每个保留、合并、上提、压平或暂不启用的动作，都必须回到阶段 A+B 的真实 Topic 与证据消息检查：

- 客观证据索引：`TAXONOMY-V2-1-AB-EFFECTIVE-TOPIC-EVIDENCE-INDEX-20260902.csv`；
- 三个优先问题的实例回放：[Taxonomy v1 优先问题清单](./TAXONOMY-V1-PRIORITY-ISSUE-REGISTER-AFTER-AB-20260902.md)；
- 全树旧口径实例审计：[Taxonomy v2 层级深度审计](./TAXONOMY-V2-HIERARCHY-DEPTH-AUDIT-AFTER-AB-20260902.md)。

证据使用规则：

1. A+B 中没有干净实例的细分，不进入当前可选树，只能放入待验证候选池；
2. 只有一个实例的细分只能标为 `◇ provisional`，不能宣称边界已经稳定；
3. 已有多个实例但无法写出互斥边界时，保留 Topic 原文，目录停在更粗的终点；
4. 不能仅因子节点少于或等于 3 个就合并，也不能为保持三级外观而制造同义 L3；
5. 已观察到相关实例、但“学习活动／专业活动”等边界尚未裁清时，可以保留一个标 `◇` 的粗粒度压力测试终点；它不算已验证节点，也不得用于需求规模结论；
6. 本轮实例只证明“结构候选有现实依据”，不等于 331 个 Topic 已完成新路径映射；正式采用前仍须逐条可逆迁移和冲突回放。

关键判断的代表性实例锚点：

| 结构判断 | A+B 代表实例 | 这批实例证明什么 |

| 保留正式测评／日常表现两叶 | `S1000-0111 / STI-44f9fa067d2d27a6f977`；`S1000-0103 / STI-098f86bc32858650572d` | 正式考试结果与日常学情反馈来源、处理目的不同 |

## 3. 关键结构为什么这样压缩

### 3.1 学习：合并薄 L2，不合并四个真实主题

A+B 旧口径中：作业 11、学习计划 2、正式测评 4、日常表现 8。四种内容均有独立意义，因此保留 L3；原来的两个二分 L2 合成一个稳定的“学习任务、计划与评价”分组。

正式测评与日常表现仍互斥：

- 正式／标准化考试事件、官方成绩、通过与否 → `正式测评、考试与成绩`；
- 课堂、练习、作业和教师观察形成的表现 → `日常学习表现与反馈`；
- 备考 → `学习计划、复习与备考`；
- 练习估分不是正式成绩。

### 3.2 教学：保留资源与进度，减少实施／评价薄包装

合并后的教材资料约 10 个旧口径 Topic，内容进度 5 个，边界有实例支撑，继续保留二分。教学方法 8、教学质量 4；课堂互动规范的代表性短候选为 `S1000-0125 / STI-4a5c15095217f662745a`（课堂聊天限制，4 条证据消息），另有 `S1000-0128 / STI-0d90f16b47afe912c2ca`（课堂参与要求，2 条）。因此暂把三个主题置于一个更完整的教学实施分组，但互动规范继续标 `◇`，不能声称边界已稳定。

`教学记录、总结与回放` 在 A+B 没有干净实例，暂移入候选池，不在当前可选树中强制占一个 L3。

### 3.3 课程运营：按生命周期与业务对象保留必要三级

- 排期分支已有可用时段 6、课程变更 25；预约／固定排课的候选锚点为 `S1000-0024 / STI-97c3d224af0c4fcda972`（开放可预约时段并保持固定周排班）及 `S1000-0124 / STI-9e030374cfe8a97f7567`（固定课程时段协商），精确分流仍待迁移验证；
- 课堂分支已有到课缺勤 19、课堂接入 11；两者不能因只有两个子节点而合并；
- 学员相关事项聚合承接、服务评价与学员权益；
- 教师相关事项聚合招聘入职、工作规范与教师结算；
- 缺勤导致扣薪仍用 `cause/business_impact/relation` 表达，不把两个业务 Topic 合并。

### 3.4 数字平台：保留 IM 基建对象，合并两个薄技术分组

账号、联系人、群治理在 A+B 旧口径分别有 4、5、14 个 Topic，是三类稳定 IM 基建事实，继续保留。技术侧旧口径有故障 8、应用使用 5、课堂工具 2、文件操作 1；将原两个薄 L2 合成“设备、应用与数字操作”。

原来零干净实例的“链接、权限与内容访问”不并入任何可选节点，先进入待验证候选池；已有设备设置实例仍归入较窄的“设备与应用配置”。

### 3.5 人际社交：唯一一对一层级直接压平

恋爱 6、同伴 4、家庭 2，以及见面 8、社群 3、玩笑 5，都有实际 Topic 支撑，保留三级。身份分支只有 MBTI 1 个实例且父子同义，直接改成终点 L2。

`玩笑、梗与语言游戏` 后续仍需回放：手机受限和骑车险情等内容应迁出，不能继续把“语气轻松”当主题。

### 3.6 娱乐创作：合并零／低证据的过细叶

- 电子游戏 4，棋牌 0：暂合为 `游戏与游玩`，具体类型保留在 Topic 文本；
- 文字创作 6、角色扮演 1：暂合为 `故事、角色设定与虚构互动`；
- 影视 4、音乐 2、体育 1、收藏 1、音视频创作 3 仍保留，但低频节点标为 provisional。

### 3.7 日常及外围领域：先停在 L2

外围分支不是从 6 个“日常生活”Topic 直接推导出多棵细树，而是按旧有效路径逐项检查后停在较粗终点：日常生活 6、宠物 1、健康 4 + 运动 1、天气 2、旅行／地点 4、校园 4、消费 1、金融交易 12、法律维权 1、公共事务 1（混合且低强度）。例如 `S1000-0018 / STI-7b5859bb7969e32bc1a1` 的主旨是未及时回复与教师休息说明，旧路径落在健康医疗，暴露了“个人近况／经历”缺口，因此 L2-048 仍标 `◇`。

`专业研究与学术发表` 保留为 `◇` 粗终点，是因为 A+B 已出现论文、投稿与研究分析相关实例，但它们在“学生学习研究”与“专业研究活动”之间仍有边界冲突；该节点只是待迁移压力测试入口，不代表已有干净专业研究正例。`职业与工作` 没有干净实例，已整体移入候选池。教育路径中的入学／专业细分、商业经营、宏观经济、交易安全、公共安全等同样不展开为可选节点。

## 5. 统计口径

可变深度不改变“一个 Topic 只有一个主路径”，但不能再默认所有终点都在 L3：

- 全局一级榜：按 L1 统计领域；
- 全局二级榜：固定按 L2 统计核心主题类目；
- L3 仅在所属 L2 内部做 drill-down；
- 终点 L2 与别的 L3 不进入同一粒度排名；
- 检索型终点榜必须同时展示 `terminal_level`；
- L2 有 L3 时，Topic 不得停在该 L2，避免父子重复计数。

## 6. 后续门禁

1. 人工先审阅本 v2.1 可变深度结构；
2. 方向确认后先生成独立的 v2.1 候选 Schema 快照，不覆盖现行 v1 或审阅台；
3. 对 A+B 331 Topic 做可逆迁移预览；
4. 用迁移结果复算每个终点节点的 Topic 数、会话数、边界冲突和上下文不足；
5. 迁移结果通过人工复核后冻结 v2.1；
6. 冻结后才修改正式 taxonomy schema、分类 schema、统计脚本与审阅台，使路径支持 2～3 层，再进入下一阶段；阶段 D 在此之前继续保持未见。
