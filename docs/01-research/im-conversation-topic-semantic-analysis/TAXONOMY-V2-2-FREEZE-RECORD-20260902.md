## 3. 已冻结的关键修正

### 3.1 学习评价保持两个互斥终点

- `L3-072 正式测评、考试与成绩`：正式、标准化或具有明确成绩结果的测评事件；
- `L3-010 日常学习表现与反馈`：课堂、练习、作业或教师观察形成的日常学情反馈。

正式测评与日常表现都属于表现和反馈，但证据来源、业务处理和后续行动不同，因此不合并。

### 3.2 教材选择与教学资料合并

教材选择、推荐、确认、获取以及教学资料、课件的讨论统一进入 `L3-073 教材、教学资料与课件`。不再按“选择动作”和“资料对象”建立容易交叉的两个节点。

### 3.3 教学内容进度与教学方法质量分轴

- `L2-023 教学内容规划与资源`：回答教什么、用什么、学到哪里；
- `L2-042 教学方法、课堂规范与质量改进`：回答怎么教、如何参与、如何评价并改进教学。

### 3.4 课程运营按主要待解决事项裁决

到课／请假／缺勤、学员费用权益、教师课酬、教师事务、课程服务不能因存在因果链而合并。每个 Topic 依据当前主要待解决事项选择主路径；因果与业务影响另作关系信息保留。

### 3.5 数字平台按用户正在解决的操作分轴

- `L3-029 技术故障与连接排查`；
- `L3-030 设备设置、应用安装与使用限制`；
- `L3-032 在线课堂与协作功能操作`；
- `L3-033 消息、文件与媒体操作`。

软件或工具只是沟通媒介时，不因为出现工具名而归入数字平台；只有数字操作或故障本身是待解决目标时才进入该领域。

### 3.6 普通闲聊先按内容归类

天气、饮食、娱乐、家庭、旅行等仍按具体内容选择主题。只有没有更具体外部议题、主要功能是持续寒暄、陪伴、关心或维持联系时，才进入新增终点 `L3-100 日常寒暄与关系维系`。

讨论阶段曾暂用 `L3-084`，但该 ID 在历史 v2 中已分配给“棋牌桌游与线下游戏”。为维持 ID 单义和历史可追溯性，冻结版本改用 `L3-100`；概念本身未改变。

### 3.7 日常生活撤销宽泛兜底

- `L2-047` 收窄并改名为 `饮食、作息与生活事务`；
- `L2-048 个人近况、经历与日常安排` 退出活跃树，状态为 `retired_overbroad`，其 ID 永不复用；
- 无稳定位置的有效 Topic 进入 `taxonomy_gap`，不得强塞入“个人近况”或“其他”。

### 3.8 外围节点按 A+B 证据收紧

- `L3-071` 改名为 `研究方法与学术项目能力`；
- `L1-011` 改名为 `教育环境与校园事务`；
- `L2-053` 收窄为 provisional 的 `校园事务与校园生活`；
- `L2-054 专业研究与学术发表` 退出活跃树，进入候选池，ID 保留；
- `L2-056` 收窄为 `消费与购买`；
- `L2-058` 收窄为 `法律与权利`。
