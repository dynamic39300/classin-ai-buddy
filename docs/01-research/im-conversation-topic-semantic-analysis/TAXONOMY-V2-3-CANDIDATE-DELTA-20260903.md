
### 定义

既有合作教师与管理方沟通，以获得、跟进或调整可分配学员及相应课量为目标。

### 纳入

- 教师询问何时能获得新学生或更多课程；
- 教师请求增加某年龄段、学科或类型的学生；
- 管理方回应正在推荐、协调或重新分配学生；
- 已在岗教师的服务表现导致学生或课量调整，且沟通主目标仍是分配与课量协调。

### 排除与相邻边界

- 招聘、签约、入职资料或入职流程 → `L3-080 教师招聘、入职与资料`；
- 教师申报自己可工作的日期／时段 → `L3-018 可用时段与排班`；
- 为具体学生确定某节课或固定周期 → `L3-075 课程预约与固定排课`；
- 缺勤、未回复、违规等纪律事项本身 → `L3-081 教师工作规范、考核与人员处置`；
- 课酬、薪资、奖励金额和发放 → `L3-079 教师课酬、薪资与奖励`。

当同一对话同时出现“纪律原因”和“学生被转走”时，以当前持续沟通的主要对象与目标判断；不能仅因存在潜在考核后果就跨入人员处置。
