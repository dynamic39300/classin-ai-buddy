## 3. 各 L1 的定义与边界

| L1 | 定义 | 主要排除 |
|---|---|---|
| 学习与学业内容 | 学习者正在学习什么、需完成什么、如何计划以及表现如何 | 教师如何教、课程如何运营 |
| 教学设计、实施与改进 | 教师选择什么内容和资源、如何组织课堂、如何评价和改进教学 | 学生自身表现、排课收费 |
| 课程运营与服务 | 课程时间、出勤、运行、学员承接、服务、权益、结算和教师合作 | 教学内容、一般技术故障 |
| 数字平台与技术 | 账号、平台空间、设备、应用、权限和文件操作本身成为处理对象 | 仅借助数字媒介完成的教学或社交目的 |
| 人际关系与社交 | 现实关系、身份、自我认知、社交安排和社群参与 | 数字群功能、娱乐作品内容 |
| 娱乐与创作 | 娱乐内容消费、游玩、收藏、创作和虚构互动 | 技能教学、健康训练、纯文件处理 |
| 日常生活、健康与出行 | 起居、个人事务、近况经历、健康、身体活动、天气和出行 | 课程运营、关系冲突、公共制度议题 |
| 教育路径、研究与职业 | 校园制度、教育路径、独立专业研究和普通职业发展 | 课程内学习任务、教师机构人事 |
| 商业、消费与金融 | 经营、购买、金融市场、宏观行业信息和交易安全 | 课程费用、兴趣收藏、普通生活支付 |
| 法律与公共事务 | 法律权利、公共安全、政策社会议题和公共运行事件 | 个人险情、账号安全、天气和个人行程 |

## 5. 从主树移出的正交字段

这些信息需要被分析，但不再占用 L1/L2/L3：

| 字段 | 候选取值 | 用途 |
|---|---|---|
| `classification_status` | `matched` / `context_insufficient` / `taxonomy_gap` / `needs_split` | 区分成功归类、上下文不足、目录缺口和 Topic 需要拆分 |
| `content_safety` | `none` / `adult_sexual` / 后续受控安全值 | 记录内容安全属性；不把成人内容当业务内容域 |
| `medium` | `group_chat` / `direct_message` / `call` / `link` / `file` / `online_classroom` 等 | 记录沟通或承载媒介 |
| `actor_role` | 老师／学生／家长／管理者等 | 记录可见角色，不决定内容主路径 |
| `cause[]` | 天气、疾病、故障、缺勤等 | 记录原因 |
| `business_impact[]` | 扣薪、退款、补课、取消、纪律处置等 | 记录业务后果 |
| `relation[]` | `causes` / `results_in` / `follow_up_to` / `rescheduled_as` 等 | 关联被拆开的独立 Topic |

领域动作属性按需使用，例如：

- `resource_action[] = select / adapt / create / find / acquire / share / use / troubleshoot`；
- `schedule_action[] = open_availability / book / confirm / reschedule / cancel / add / make_up`；
- `assessment_stage = preparing / taking / resulted`；
- `evidence_status = official / estimated / observed`；
- `financial_party = learner / teacher / organization`。
