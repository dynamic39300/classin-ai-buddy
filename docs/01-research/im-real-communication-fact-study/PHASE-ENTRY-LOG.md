# ClassIn IM 真实沟通事实研究阶段进入日志

## 2026-08-29：由预研进入正式研究

### 已达成的共识

1. 先把真实沟通事实研究清楚，再讨论基础 IM、AI 辅助和产品形态；
2. 既有分析不整体丢弃，但降级为 Round 0 预研资产，不沿用未经验证的语义结论；
3. 正式执行前先形成研究方法文档，并在方法讨论中完成数据结构、缺失、脏数据和清洗规则审计；
4. 小规模标注实验必须优先保证样本覆盖与样本保全，避免取偏、漏样和不透明替补；
5. 研究维度要尽可能全面，但不能为了“全面”预写产品答案；
6. 每项指标都必须能解释分析单位、分子、分母、去重、多标签和缺失；
7. 清洗不等于修饰数据：原始层只读，修正规则可审、可逆、可统计影响；
8. 第一部分通过质量 Gate 后，才进入第二部分能力推导。
