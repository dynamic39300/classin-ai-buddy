正式事实研究从原始数据重新开始。上一轮预研材料继续封存以保留历史，但不得作为 P1–P5 的分析输入、标签来源、抽样依据、案例选择依据、工作簿模板或结论参照。

### 原表真实字段的当前授权

2026-08-30 用户确认原始 Excel 已经完成脱敏，允许仓库外受限试标材料保留原表字段和值，便于标注时回查。这里的“真实”严格定义为“原表已有值”：

- 允许：原表 Excel 行号、`clusterid`、`id`、`msgid`、`sourceuid`、`strtalker`、`replymsgid`、正文及其他原表字段；
- 禁止：外部身份反查、补充原表之外的信息、将昵称/ID解释为外部真人身份；
- 原表值只进入仓库外受限材料，仓库内仍只记录路径、字段名、聚合 QA 和不可逆指纹；
- 大整数标识必须按文本保存，避免 JavaScript/Excel 精度损失。

## 5. 从零分析的新起点

Pilot 0 首轮改为开放编码：

1. 内容盲抽样，不根据关键词、主题或产品价值选样；
2. 两名标注者独立阅读同一脱敏片段；
3. 先记录可观察事实与自由描述，不提供教学主题菜单；
4. 保留“无明确事项、纯表达、上下文不足、无法理解”等正常结果；
5. 完成首轮后再归并同义开放码，形成候选 Codebook；
6. 用新的独立样本验证 Codebook，验证通过后才允许扩展统计。
