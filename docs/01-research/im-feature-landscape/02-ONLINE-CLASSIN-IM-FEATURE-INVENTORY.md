# ClassIn PC 线上 IM 入口与功能全集

## 1. 阶段结论

本轮已对 Notion `#1 Classin IM 功能设计现状`做全文读取，并对提供的 60 张 PC 产品截图完成逐图、控件级核验。基于本轮材料，ClassIn 线上 IM 不是单纯的聊天窗口，而是一个由以下部分共同构成的消息域：

```text
全局消息工作区 + 班级场景浮窗
  + 好友/组织/班级身份关系
  + 班级群与 1:1 顺序消息流
  + 公告、@提醒、系统事件和官方内容
  + 本地/云盘资源消息
  + 名片与临时教室结构化业务消息
  + 公开课通知和课堂动作
```

在本轮证据覆盖范围内：

- 确认 **2 个外部主入口**、**14 个 IM 内部或消息内动作入口**；
- 归一化登记 **104 项当前线上可见/可用 Feature**，其中基础会话、关系、Composer 与消息格式 75 项、通知/业务动作 18 项、角色/生命周期 11 项；
- 另登记 **4 项 ClassIn AI 边界证据**，并排除 **1 项非 ClassIn 外部应用悬浮入口**；没有证据证明线上 IM 已有可对话、可调用工具或执行任务的 AI Agent；
- 单列 **9 项用户已确认的负向事实**，避免把“未截图”误写成“不支持”；
- 原 **12 项待审阅/补证据问题**均已完成用户校准，功能有无已闭合；规则、异常和生命周期细节按共识延后到需求设计阶段。

这里的“全集”指对本轮 Notion、截图与用户确认材料的全量还原。移动端、Web 端、服务端协议、灰度差异、异常路径和未提供页面仍不在事实覆盖内。

## 2. 范围、事实规则与来源

### 2.1 纳入范围

- ClassIn PC 一级导航“消息”及其完整消息工作区；
- 班级课程详情右侧“聊天”及班级聊天浮窗；
- 通讯录、添加菜单、全网搜索、班级资料侧栏；
- 班级群、个人私聊、公开课通知/详情、ClassIn 助手官方信息流；
- 文本、表情、@、截图、文件、名片、图片、视频和临时教室；
- 老师、班主任、助教和学生的已确认权限差异；
- 线上 IM 页面中可见的 AI 邻接入口或内容，但独立于基础 IM 统计。

### 2.2 不纳入范围

- 当前仓库 Demo 的实现状态与差异；该工作属于第三阶段；
- 班级课程、待办、作业、在线教室内部功能本身；只登记它们与 IM 的入口、对象引用、动作和状态回写；
- 未被材料证明的移动端、Web、推送协议、消息存储、风控、审计、已读回执和多端同步；
- 未来 Agent 设计、竞品能力或 2.0 候选方案。

### 2.3 事实标记

| 状态 | 含义 |
| --- | --- |
| `CONFIRMED` | 一手文字、截图或用户直接确认足以证明该项 |
| `MULTI_SOURCE_CONFIRMED` | 至少两类一手证据互相支持 |
| `VISIBLE_ONLY` | 控件或内容可见，但后续动作、适用范围或规则未证明 |
| `PARTIALLY_CONFIRMED` | 主链路已证明，但异常、权限或完整状态仍不足 |
| `UNKNOWN` | 现有证据不足，不推断 |
| `CONFLICT` | 证据直接矛盾，暂停采用 |
| `EXCLUDED` | 截图中可见，但已确认不属于 ClassIn 或不属于本研究对象 |

本清单不枚举“完全不存在且没有参照意义”的虚构功能。已被用户明确确认不支持的能力进入第 8 章负向事实表，不混入 Feature 数量。

| --- | ---: | --- |

| 对线上 PC 产品绝对全集的完整度 | **约 88%** | 有限截图不能排除未提供入口、账号/角色/灰度配置、版本差异和隐藏动作 |
