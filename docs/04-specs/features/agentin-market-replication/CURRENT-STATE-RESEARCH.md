## 3. 线上入口与页面跳转

```text
班级课程详情页
  → 左侧“AI 应用”区域加号
    → “添加智能体”独立窗口（Modal/Window）
      → 最大化按钮
        → “添加智能体”全屏独立页面
```

### 3.1 班级详情入口

- 入口位于班级课程详情左侧栏的“AI 应用”标题行；
- 标题行右侧同时可见齿轮和加号；
- AI 应用列表中已经存在多个 Agent 项目，如“AI 助教”“AI 学情”“李白”“应用题思路点拨”；
- 截图与 Notion 文字只证明“点击加号进入 AgentIn”，没有证明齿轮功能或具体授权过程。

### 3.2 独立窗口

- 窗口标题为“添加智能体”；
- 右上角依次为刷新、分隔线、最小化、最大化、关闭；
- 窗口覆盖在原班级详情页之上，背景页面仍可见；
- 最大化后进入同一 AgentIn 页面结构，不是另一套信息架构。

## 4. AgentIn 首页信息架构

### 4.1 内部左侧导航

- 品牌标题：`AgentIn`；
- 导航收起图标；
- 一级项：`首页`（当前选中）、`我创建的`；
- 分组标题：`我的收藏`；
- 收藏列表：`我的班级知识库`（带图钉）、`数学思维教练`、`鲁迅`、`杜甫`、`学小伴`、`李白`、`xinlei的替身`；
- 底部账号区域：头像、`wangxinlei`、角色 `学生`、切换箭头、带数字 4 的通知铃铛。

说明：账号角色“学生”是截图事实。当前 TeacherIn 代码的不变量是教师端专属，因此 Demo 接入时不能把该学生身份复制成当前教师身份；应由宿主身份取代或不重复展示。

### 4.2 顶部控制区

- 学段选择：`小学·二年级`；
- 搜索框占位：`搜索智能体`；
- 页面有独立纵向滚动条；
- 全屏窗口的顶栏继续显示“添加智能体”和窗口控制。

### 4.3 猜你喜欢

- 标题：`猜你喜欢`；
- 操作：`换一换`，带刷新图标；
- 全屏截图显示四张推荐卡：`每日名言`、`成语溯源与应用专家`、`地理百科大全`、`孔子`；
- 卡片展示头像、名称、简介、收藏人数、作者；
- 独立窗口较窄时只显示三列，证明该区域会随可用宽度减少列数。

### 4.4 分类和排序

- 分类：`语文`（当前选中）、`数学`、`科学`、`道德与法治`、`其他`；
- 排序：`最热`（当前选中）、`最新`；
- 未观察到额外筛选、分页器或无限加载提示。

### 4.5 可添加智能体列表

截图可识别的卡片包括：

- 豆神AI 私教问答、鲁迅、李白、职业领航员、阅读伙伴；
- 孔子、课外书单推荐、杜甫、知识理解、国学大师；
- 我是小老师、苏格拉底助手、学生语文作文辅导专家、每日名言、认真读古诗；
- 文言文翻译官、成语老师、试题内容提取【兼容ClassIn…】、提示词领航员、成语溯源与应用专家；
- 推荐一部动画片、写理由小能手、童话心愿发布会、课间游戏设计玩伴、美景小诗—AI小助手；
- 课间游戏评价智能体、人物科普简介卡、写雨小助手。

每张卡片的共同字段是头像、标题、截断简介、收藏人数和作者；部分卡片有额外标识，如“热门”。

### 4.6 当前场景不支持添加

可添加列表之后有独立标题：`以下智能体当前场景不支持添加`。截图可识别：

- 汉字笔顺、NOBOOK、作业拍照校正、题库出题；
- PowerUp点读书、总结大师、提炼纪要、组织题库出题。

卡片视觉仍延续市场卡片；`提炼纪要`额外显示“知识库”标识。截图没有展示点击这些卡片后的解释方式，因此不推断禁用弹窗或原因文案。

## 5. 可观察的视觉规则

- 纯白主背景、近黑主文字、灰色次级文字；
- 大圆角矩形卡片，1px 浅灰边框和非常轻的阴影；
- 卡片头像为圆形；
- 当前导航项使用浅灰填充，分类当前项使用深色加粗；
- 搜索框、学段下拉和“换一换”均为胶囊形控件；
- 内容区在全屏宽度采用最多五列，在独立窗口宽度采用三列；
- 页面头部和分类/排序区域在长列表滚动过程中保持稳定位置的迹象明显，但仅凭三张分段截图无法证明全部 Sticky 行为。

## 6. 已知与未知

### 已知

- AgentIn 的核心形态是 Agent 市场与个人收藏导航；
- 入口与当前班级场景相关；
- 市场存在“可添加”和“当前场景不支持添加”两种兼容状态；
- 页面同时提供学段、搜索、推荐、学科分类和热度/时间排序的发现机制；
- 页面可以在独立窗口和全屏窗口之间切换。

### UNKNOWN

- Agent 详情页的完整字段和操作；
- “收藏”“创建”“添加到班级”“授权”的具体交互、成功/失败状态；
- 教师、班主任、助教、学生在 AgentIn 中的精确权限矩阵；
- “我创建的”页面和收藏项点击后的页面；
- 搜索、分类、排序和“换一换”的真实数据逻辑；
- 不支持添加的判定规则及解释文案；
- 是否支持第三方发布、审核、版本管理、复制或编辑 Prompt。

上述未知项不进入本轮静态复刻。它们可以在获得新的页面证据后进入下一版 PRD。
