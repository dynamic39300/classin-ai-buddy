# 02 — 交付单课件目标到 Artifact

**What to build:** 教师可以基于已确认的 ContextSnapshot 提交单课件目标，完成结构化补参和计划确认，通过稳定过程事件得到可审阅的课件 ArtifactDraft。

**Blocked by:** 01 — 交付 Core Context Proposal 与 Snapshot。

**Status:** ready-for-agent

- [ ] 目标、Task Type 和 Snapshot 创建标准单课件 WorkBuddyRun。
- [ ] 已知 Context 不重复询问；必需补参可提交、修改并保留摘要。
- [ ] 计划展示步骤、预期产物、能力摘要和等待点，教师可确认或返回修改。
- [ ] 显式命令推进稳定 RunEvent，不依赖随机数或页面计时器。
- [ ] 执行详情展示教师摘要、能力追踪和脱敏 ContextProjection。
- [ ] 生成带稳定 ID、版本、来源步骤、验证和真值标签的课件 ArtifactDraft。
- [ ] Run/Artifact/Context 面板切换、历史恢复、键盘与视觉验收通过。
