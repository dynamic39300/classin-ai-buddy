# 05 — 交付任务历史管理闭环

**What to build:** 教师可以在二级导航内识别和管理近期任务，通过相对时间、滚动和操作菜单完成重命名、置顶与删除的本地 Demo 交互。

**Blocked by:** 02 — 交付教师 AI Agent 两级导航闭环。

**Status:** completed

- [x] 历史条目默认显示相对时间，Hover、Focus 或选中时显示 `…` 操作。
- [x] `…` 菜单可用键盘打开，并提供重命名、置顶/取消置顶和删除。
- [x] 所有变更仅存在于当前 Demo 内存态并有可见反馈，不伪装持久化。
- [x] 置顶任务稳定排在普通任务之前，状态变化不强制改变滚动位置。
- [x] 删除当前任务不会留下不可解释的空白页面。
- [x] 历史区域独立滚动且不形成第三根导航栏。
