# 02 — 交付教师 AI Agent 两级导航闭环

**What to build:** 教师可以从 ClassIn 一级导航进入 AI Agent，并在同一列扁平二级导航中到达新任务、近期任务、能力资源、定时任务与设置；学生端不出现该入口。

**Blocked by:** 01 — 收敛 ClassIn PC 产品基座与工程事实源。

**Status:** completed

- [x] `AI Agent` 是教师一级菜单，与现有 ClassIn 工作模块同级，所有嵌套 Agent URL 保持该一级项选中。
- [x] AI Agent 二级面板宽度、密度、Token 和滚动所有权符合已锁定视觉与交互规范。
- [x] 二级面板直接显示新建任务、近期任务、Skills、Tools、内容、我的文件、定时任务和设置，不形成第三级菜单。
- [x] 1440×900 默认可见六条历史，更多历史在同一 Section 内滚动。
- [x] 所有能力入口均可到达，并在未实现时显示明确的 M3 真值占位。
- [x] 学生端导航和路由不暴露教师 AI Agent。
- [x] 浏览器旅程覆盖从教师角色选择到 AI Agent、能力入口、离开并返回。
